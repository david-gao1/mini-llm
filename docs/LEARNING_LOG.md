## P1-01 · m01_tokenizer（分词器）

1. GPT-2 词表有 50257 个 token。为什么不直接按字符（a-z）编码，而要用 BPE 这种子词算法？
2. `encode("Hello") → [15496]` 但 `encode("hello") → [31373]`，大小写得到不同的 token ID。这对模型意味着什么？
3. 如果你换一个完全不同的 tokenizer（比如中文分词），模型的哪些部分需要跟着改？

## P1-02 · m02_data_loader（数据加载器）

1. 训练数据里 `target` 比 `input` 右移一位（`target[i] = input[i+1]`）。为什么要这样构造？模型在学什么？
2. `context_length = 1024` 意味着模型一次最多看 1024 个 token。如果一篇文章有 5000 个 token，它怎么办？会丢信息吗？
3. 滑动窗口的 `stride` 如果设成 `context_length` 的一半（有重叠），训练会有什么不同？好处和代价各是什么？

## P1-03 · m03_attention（注意力机制）

1. 「因果掩码」让每个 token 只能看到它之前的 token。如果去掉这个限制（让它看到整句话），模型还能用来做生成吗？为什么？
2. 多头注意力有 16 个头，每个头各自算一份注意力。为什么不用一个大头？多个小头有什么好处？
3. 自注意力的计算量和序列长度的关系是什么？（提示：不是线性的）这对实际使用有什么影响？

## P1-04 · m04_model（GPT 模型）

1. GPTModel 的 forward 输出形状是 `[B, T, V]`（batch、序列长度、词表大小）。最后一维的 50257 个数代表什么？它们加起来等于 1 吗？
2. 模型里有 `tok_emb`（token 嵌入）和 `pos_emb`（位置嵌入）两个表。如果去掉位置嵌入，模型会失去什么能力？
3. 163M 参数的模型，占多少内存？（提示：一个 float32 参数占 4 字节）

## P1-05 · train.py（预训练）

1. 训练时用的是 cross_entropy loss。这个 loss 在衡量什么？loss = 3.3 和 loss = 5.0，直觉上差多少？
2. 为什么要分 train set 和 validation set？如果只用 train set 算 loss 来判断模型好坏，会出什么问题？
3. checkpoint 保存的是「验证集上 loss 最低」的那个版本，而不是最后一个 epoch 的。在什么情况下这两个会不一样？

## P1-06 · 训练优化

2. early stopping 在验证集 loss 连续 N 轮不下降时停止训练。N 太小和太大分别有什么风险？
3. MPS（Apple Silicon GPU）和 CUDA（NVIDIA GPU）都能加速训练。加速的原理是什么？为什么 GPU 比 CPU 快这么多？
